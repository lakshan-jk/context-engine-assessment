Cross-cutting concerns
Fault tolerance — failure degrades, never 500s Grounding — answer only from context Confidence — honest, min of two signals Cost control — trim + cache + tier Multilingual — English keyword, LLM for the rest
Scaling to 10M MAU (bottlenecks in order):
  • App tier — already stateless → scale flat behind the load balancer.
  • Cache — in-memory → Redis via the Cache interface. Panchang-by-date serves everyone; shields upstreams.
  • LLM (the real cost) — response caching, per-tier model routing, streaming, token budgets.
  • Protect — per-service circuit breakers, per-user rate limiting, idempotency keys, queues for async (e.g. alert fan-out).
  • Observe — OpenTelemetry tracing across the fan-out + a CI eval harness so answer quality can't silently regress.
  • Don't build yet — vector retrieval (keyword + config is enough at this catalog size).
